# Сметная

Сайт и браузерный прототип для заявки «Студенческий стартап». «Сметная» — рабочее название интерфейса.

На главной можно попробовать поиск расценок, перейти к тарифам и открыть кабинет. Условия платных планов оставлены без цен, пока они не согласованы.

## Демонстрация

1. На главной нажмите «Открыть смету фундамента». Откроется спецификация с 22 учебными позициями.
2. Перейдите в «Подбор». Для земляных работ выберите вариант с погрузкой. При объёме 32 м³ и расценке 520 ₽/м³ сумма строки составит 16 640 ₽. В расчёте и предпросмотре видны выбранная работа и исходная строка.
3. Переключитесь на коммерческую смету. В замечаниях укажите цену арматуры и подтвердите или обновите цену мастики. Сравните предложения поставщиков и выберите регион цен. В составе стоимости работ перечислены исходные работы и их объёмы.
4. В предпросмотре проверьте источники, итог и состав работ. Сохранить документ в PDF можно через печать браузера. Правки и сохранённые версии доступны в этом браузере.

В правом нижнем углу карточки сметы нажмите круглую кнопку «Сметная AI». Учебный чат сравнивает расценки, объясняет изменение региональной цены или выбора поставщика и собирает вопросы по замечаниям обоих режимов. Из чата можно подтвердить вариант погрузки, открыть спорную строку и скопировать вопросы. Все ответы вычисляются локально по текущей смете.

Для новой сметы доступны учебная спецификация и ручное заполнение. К защите запланирован реальный импорт одного шаблона Excel. Основная разработка, RAG, поддержка XML и JSON и проверка файла локальной сметы в ГРАНД-Смете запланированы после получения гранта. Расценки и региональные предложения в макете демонстрационные.

## Локальный запуск

Из папки `prototype` выполните:

```sh
npm ci
npm run dev
```

Чтобы проверить сборку, выполните `npm run build`, затем `npm run preview`. Адрес будет указан в терминале.

## Публикация на GitHub Pages

1. Создайте отдельный публичный репозиторий и перенесите в его корень содержимое `prototype`, включая `.github`, `.gitignore` и `package-lock.json`.
2. В **Settings → Pages → Build and deployment** выберите **GitHub Actions**.
3. Отправьте код в ветку `main` или запустите **Publish demo to GitHub Pages** вручную через вкладку **Actions**.
4. После успешной публикации возьмите адрес из **Settings → Pages**. Откройте его в приватном окне и проверьте главную, поиск расценок, открытие примера и предпросмотр расчёта.
